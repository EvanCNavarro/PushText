# 0.6.1

## Improved

- **The Globe-key note is quieter, and you can dismiss it.** If you use Globe as your dictation key
  and macOS also has an action on that key, PushText mentions it once - as a note rather than a
  warning, with a Dismiss that sticks.

  It used to be an orange alert with no way to silence it, which read as though something were
  broken when nothing was. Setting **Press 🌐 key to → Do Nothing** in Keyboard settings still
  removes it entirely, and remains the tidier answer if you never use Apple's own dictation.
