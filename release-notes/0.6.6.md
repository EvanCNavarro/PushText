# 0.6.6

## Changed

- **The menu-bar icon is the app's own mark now.** It used to be a stock system waveform, which is a
  different shape from the icon in your Dock - so PushText showed you two different logos for the
  same app. Both are the same mark from this release.

- **You can see at a glance when PushText is listening.** While dictation is running the menu-bar
  mark inverts: the bars are knocked out of a filled square instead of standing on their own. It
  reads the same way on a light or a dark menu bar, because macOS tints it rather than the app
  picking a colour.
