# 0.6.7

## Improved

- **Dictation History stays fast, however long you use PushText.** The window read the entire
  history file every time it opened or updated, and that file grew forever - it only ever showed the
  most recent 500 dictations, but it still read everything behind them. After twenty thousand
  dictations that was a four-megabyte file and a visible pause. It is now kept trimmed on disk, so
  opening the window costs the same in a year as it does today.
