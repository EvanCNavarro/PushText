# 0.4.2

## Fixed

- **The Globe key now belongs to PushText alone.** If you use Globe as your dictation key, macOS was
  also running its own action on it - the emoji viewer, an input-source switch, or Apple's dictation
  - so a single press did two things. PushText now takes that key for itself while it is your
  dictation key, and the system action stays out of the way.

  Every other key is untouched: bind Right Shift and it still types capitals. Globe is the only key
  with a system action worth swallowing, and only while you have chosen it.
