# 0.4.0

## New

- **A sound when dictation starts and stops.** A short tone when PushText begins listening, a lower
  one when it stops. Useful when the HUD is behind a full-screen window and the only other way to
  know the key registered is to start talking and hope.

  On by default, and there is a switch for it under **Sound** in the menu. Turning it off stays off.

## Fixed

- **The update mark now appears while PushText is running.** It only ever asked once, at launch, so
  it could only tell you about releases that already existed when you started the app - and even
  then it did not redraw when the answer came back. Both are fixed: it re-checks quietly in the
  background and whenever you open the menu, and the mark on the menu bar icon, the ··· button and
  the Check for Updates row now update themselves.

  PushText still never opens an update window on its own. The mark is the whole notification.
