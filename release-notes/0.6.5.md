# 0.6.5

## Fixed

- **Windows no longer open behind the menu.** Choosing something from the menu-bar panel - the
  update dialog, Dictation History, the dictionary - used to put that window UNDERNEATH the panel,
  which covered part of it. The update dialog was the worst case: the panel sat over its Install
  button, so the only thing you could reach was "Skip This Version". The menu now closes when you
  pick something from it, the way a menu should.

## Changed

- **A cleaner app icon.** The bar underneath the waveform is gone and the bars are centred, so the
  icon matches the menu-bar symbol and the recording indicator instead of being the only place with
  a line under it.
