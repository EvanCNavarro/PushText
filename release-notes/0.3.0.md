# 0.3.0

## New

- **Your dictation history has a real viewer.** "View History" opens a window with one card per
  dictation - what you said, when, and how long it took - newest first. Search across every
  transcript, and copy any one of them with a single click.

  Before this it handed you a `.jsonl` file in a text editor: one JSON object per line, timestamps
  as raw ISO strings, and no way to find anything.

The file itself is still yours and still plain text - "Open File" inside the viewer opens it, and
nothing about where it lives has changed. History remains read-only here, and it never leaves this
Mac.
