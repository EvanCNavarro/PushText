# 0.2.5

## Fixed

- **The permission button no longer opens two things at once.** Pressing it used to raise the macOS
  "PushText would like to control this computer" dialog *and* System Settings at the same time, which
  is one affordance too many - the dialog already has an "Open System Settings" button.

  It is sequential now. The first press asks macOS, which is what puts PushText in the Accessibility
  list. If you have already been asked once, the press takes you straight to System Settings, because
  macOS only ever shows that dialog a single time.
