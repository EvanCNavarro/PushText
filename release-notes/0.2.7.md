# 0.2.7

## Fixed

- **The permission warnings now go away once you fix them.** Granting Accessibility left the menu
  still showing "Access was granted before and has stopped working", because PushText remembered the
  failure from launch and never checked again.

  It re-checks when you open the menu, and it re-arms the hotkey at the same time - so you no longer
  have to relaunch PushText after granting a permission. The warning only clears once dictation
  genuinely works again, not merely because System Settings says the switch is on.
