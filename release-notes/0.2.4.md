# 0.2.4

**Fixes granting Accessibility.** If PushText was not in the System Settings list, this is why.

## Fixed

- **PushText now appears in the Accessibility list.** That list only contains apps which have ASKED
  for the permission, and PushText never asked - so opening System Settings showed every other app
  and nothing to switch on for this one. Pressing the fix-it button now asks first, which puts
  PushText in the list, and then takes you there.
- **"Reset & Open Settings" no longer leaves you with nothing to click.** Clearing a stale entry
  removed the only row there was. It now clears the old entry and registers a fresh one before
  opening the pane.

If you granted Accessibility to an older build and it stopped working, this is the release that
makes the fix-it button actually finish the job.
