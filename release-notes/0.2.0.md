# 0.2.0

Text cleanup, which 0.1.0 shipped without, plus an icon, a hotkey you can change, and a HUD that
says what it is doing. Still entirely on this Mac - no account, no network call, nothing leaving the
machine.

## New

- **Text cleanup, wired into dictation and off by default.** 0.1.0 listed this under "not in this
  release"; it now runs between the transcript and the insertion. It is a **setting**, not a
  constant, because it is not free - see Measured below. Toggle it in the menu.
- **Choose which key dictates.** Right Option, Right Command, Right Control, Right Shift or Left
  Option. Right Option remains the default.
- **An app icon**, in the same family as TermTile.
- **Copy the last transcript** from the menu, as plain text.
- **The HUD shows a spinner while it works**, so a slow cleanup reads as busy rather than stuck.
- **Cancel keeps working after you let go.** Through transcription and cleanup, right up until the
  paste begins. With cleanup on that window is around 4 seconds, which is long enough that someone
  will reach for the key.
- **A refused press tells you it was refused** instead of silently doing nothing.

## Fixed

- **Double-press latching never worked** - a race lost by about 4 ms. Tap-versus-dictation is now
  decided by how long the key was held, not by which state won.
- **A broken microphone grant now offers to ask again.** It used to send you to System Settings,
  where an app with no recorded grant has nothing to toggle.
- **Cleanup no longer rejects a grammar fix.** Changing "fails" to "fail" for subject-verb agreement
  was being scored as invented content and thrown away; a guessed word substitution still is.
- **Channel selection reads the buffer's own layout** instead of inferring it, which was wrong for
  multi-channel audio delivered as several interleaved buffers.

## Measured

Release-to-text, on real dictations of four utterances:

**Cleanup off** - n=4: mean **206 ms**, median 196 ms, range 158-275 ms.

**Cleanup on** - n=21, and the summary that matters is not a mean. The distribution is **bimodal**,
because the prewarm started at key-down either finishes before your transcript arrives or
contributes nothing:

- **fast, 9 of 21 runs (43%)** - mean **624 ms**
- **slow, 12 of 21 runs (57%)** - mean **3957 ms**

That is the honest reason cleanup defaults to off. If you want tidier text and can accept a
multi-second pause on more than half of your dictations, turn it on.

All figures are from this one machine and are not a distribution.

## Not in this release

- **Context-aware formatting per frontmost app.** Withdrawn rather than deferred: the only problem it
  ever named - smart quotes in a terminal - does not occur. The recognizer emits straight quotes,
  cleanup returns pure ASCII, and macOS quote substitution does not fire on a paste.
- **The interleaved audio path has still never run against real audio.** No input device here reports
  more than one channel. The logic is covered by tests; the layout has not been seen in the wild.
