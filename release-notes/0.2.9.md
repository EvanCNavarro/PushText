# 0.2.9

## New

- **The custom dictionary has a real editor.** "Edit Dictionary" opens a window with one row per
  rule - what you say on the left, what PushText types on the right - with buttons to add and remove
  entries. It saves as you type.

  Before this it handed you a `.jsonl` file in a text editor and left you to keep the format valid.

Your existing entries are picked up as they are, and you can still edit the file by hand if you
prefer - the editor re-reads it each time it opens.
