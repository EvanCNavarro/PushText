# 0.6.10

## Changed

- **Updated the component that installs updates.** PushText uses Sparkle to check for and install new
  versions; it moves from 2.9.3 to 2.9.6, which carries two security fixes from the Sparkle project.
  Neither one is reachable the way PushText uses it, so this is housekeeping rather than a response
  to a problem — but it is the part of the app that writes to your machine, and it should not sit
  behind.
