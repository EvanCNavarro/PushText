# 0.2.3

A fix for the update indicator that 0.2.2 introduced.

## Fixed

- **The menu-bar icon was invisible while an update was waiting.** When PushText marked the icon to
  tell you about a new version, the icon itself turned black - and on a dark menu bar that is
  nothing at all. The dot was there; the waveform beside it was not. Both are visible now, in light
  and dark.

The `...` button and the "Check for Updates" row were unaffected and marked correctly in 0.2.2.
