# 0.4.1

## Fixed

- **The Globe key can be your dictation key.** Clicking the Hotkey field and pressing Globe used to
  beep and change nothing. It works now, and so do both sides of every modifier - Left and Right
  Command, Option, Control and Shift.

  If you pick Globe, check **System Settings ▸ Keyboard ▸ "Press 🌐 key to"**. macOS runs its own
  action on that key before any app sees it, so unless it is set to **Do Nothing** you will get the
  emoji viewer or Apple's dictation alongside yours. PushText tells you when this applies and links
  straight to the setting.

  Globe is not the default: it only exists on Apple keyboards, and on anything else it sends nothing
  at all.
