# 0.1.0

First tagged build. **This release does not transcribe speech yet** — it is the app shell, the
packaging path, and the parts of the pipeline that do not need macOS 26.

## What works

- Menu-bar app (`LSUIElement`), signed, with the Sparkle update framework embedded.
- The dictation state machine, including a watchdog that closes a capture the hotkey release never
  closed — the failure mode where the microphone silently stays open.
- `MockTranscriptionEngine`, which returns canned phrases so the rest of the pipeline can be built
  and exercised end to end.

## What does not work yet

- **Speech recognition.** `SpeechAnalyzer` is a macOS 26 API and its SDK ships with Xcode 26.
- **Text cleanup.** `FoundationModels`, same constraint.
- **The hotkey, audio capture, injection and HUD** are declared as protocol ports and not yet
  implemented (backlog #3–#7).

## Notes

Run `scripts/setup-dev-signing.sh` before granting any permission. Ad-hoc signing produces a fresh
code identity on every build, which silently revokes every macOS privacy grant.
