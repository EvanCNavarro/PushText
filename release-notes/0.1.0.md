# 0.1.0

First tagged release. Push-to-talk dictation that runs entirely on this Mac - no account, no
network call, nothing leaving the machine.

## What works

- **Hold right Option to dictate, release to insert.** Driven end to end against the real
  frameworks, not the mock: hotkey edge, capture, transcription, insertion, and back to idle.
- **On-device transcription** through `SpeechAnalyzer` / `SpeechTranscriber` (macOS 26).
- **Insertion by pasteboard and a synthetic Command-V**, carrying the transient, concealed and
  auto-generated pasteboard markers so clipboard managers do not archive what you dictated.
- **A recording HUD** with a live level meter, and cancel and confirm controls.
- **A custom dictionary** applied to each transcript, as plain JSONL. `SpeechTranscriber` cannot be
  biased toward your vocabulary - measured in `docs/verification/task13-contextual-strings.md`,
  where contextual strings produced byte-identical transcripts - so this post-pass is the only
  mechanism there is for proper nouns.
- **History as plain JSONL** under Application Support: readable with `tail`, deletable with `rm`.
- **A capture watchdog** that closes a capture the hotkey release never closed - the failure where
  the microphone silently stays open.
- **Developer ID signed and notarized**, with Sparkle updates whose appcast signature is verified
  against the public key compiled into this build before the release is ever published.

## Not in this release

- **Text cleanup.** `FoundationModelsCleanup` is implemented and measured but is not wired into the
  dictation path (#94). Transcripts are inserted as the recognizer produced them.
- **Context-aware formatting** per frontmost app (#18).
- **The remainder of permission recovery UX** (#6).

## Measured

Release-to-text was 224 ms on a real dictation of a 50-character utterance. That is one sample on
one machine, not a distribution.
