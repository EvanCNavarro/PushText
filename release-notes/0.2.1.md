# 0.2.1

**Fixes a crash on launch.** If you installed 0.2.0, it quit the moment you opened the menu. This
release fixes that.

## Fixed

- **PushText crashed on startup for anyone who did not build it themselves.** The GitHub icon in the
  menu was loaded through a path that only exists on the machine that compiled the app, so the
  released build could never find it and stopped rather than carrying on. Nothing was wrong with your
  Mac, your permissions, or your settings.

Everything in 0.2.0 is unchanged - text cleanup, the configurable dictation key, the copy button, the
HUD spinner and the app icon are all still here.
