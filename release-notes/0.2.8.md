# 0.2.8

## Fixed

- **"Edit Dictionary" now opens the dictionary.** It used to hand the file to macOS, which answered
  "There is no application set to open the document" and stopped there. PushText's files are plain
  text, so they now open in your text editor.
- **"Show History File" is now "Open History File",** and it opens the transcripts instead of only
  pointing at them in Finder. Revealing worked, but double-clicking the file ran into the same wall.

If no text editor can be found, both fall back to showing the file in Finder rather than doing
nothing.
